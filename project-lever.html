Build overview

This mechanism was meant to be simple, adjustable, and easy to reason about. I wanted the motion to stay clear and the final design to be easy to tweak when the geometry needed work.

The page is still being filled in, but the main goal was to keep the lever motion controlled and the assembly straightforward.

Design notes

Components and architecture

The mechanism uses a compact linkage, pivots, fasteners, and a simple input/output layout so the motion path stays clear and easy to understand.

Design decisions

I focused on a lever ratio that was easy to control and a load path that stayed predictable. The adjustable geometry makes it easier to test different setups.

Testing and next iteration

The next step would be to test the motion under load, measure the travel, and adjust the linkage if the output isn’t as smooth or linear as expected.
